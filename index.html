Distribute a bulk catch-up delivery
Sometimes the unit doesn't catch up lot-by-lot — they just hand over a lump total (e.g. "5 extra pieces") covering several already-short lots at once. Enter the total and the date received, then tap Auto-distribute — it only applies pieces to shortfalls that happened on or before that date (based on when the short slip actually happened, not the lot's original stitch date), oldest first. Lots that haven't been touched at all yet are skipped on purpose. Anything that can't be placed (no eligible shortfall yet) is banked automatically and stays reserved — it'll get pulled in the next time you auto-distribute and an eligible shortfall exists, it never gets force-applied to a later one.

Backup PIN

One PIN, shared across every device — set it once and it works the same everywhere. Use this if Face ID isn't available on a device. Anyone with this PIN can confirm, so keep it to yourself.

Import everything from Excel

One tap, one wait: imports all 418 sorts, then all 2,218 lots under them — each lot registered already-confirmed, sitting fully in stitch. From there, you build every send-to-washing, washing-receiving, and deposit slip yourself, partial or full amounts. Safe to tap more than once; it skips anything already imported.

Backup & restore

Downloads everything — every sort, lot, and slip — as a single file you keep yourself, outside Firebase entirely. Do this regularly, especially before any big batch of changes. If something ever goes wrong (data deleted, a bug, anything), you restore from the most recent one of these.
To restore: choose a backup file below. This writes those exact records back — anything currently in the database with the same ID gets overwritten. It does not delete records that aren't in the backup. Needs your Face ID.

Data integrity scan

Scans every lot in the register for impossible numbers — received more than sent, deposited more than received, pieces sent exceeding total, etc. These can happen from a double-confirmed slip or a mis-edit. Shows each problem lot with a one-tap repair that sets the counters back to the correct values based on all confirmed slips for that lot.
